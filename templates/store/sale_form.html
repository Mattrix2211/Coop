Vente

Comment faire une vente ?
  1. Sélectionnez les produits — cliquez sur les articles dans la grille pour les ajouter au panier. Utilisez la barre de recherche ou les filtres par catégorie pour trouver rapidement un article.
  2. Choisissez un client — obligatoire pour valider. Commencez à taper le nom dans le champ client.
  3. Choisissez le paiement —
    • Espèces : cliquez sur les billets/pièces remis. Le rendu monnaie est calculé automatiquement.
    • Chèque / Autre : saisissez le montant encaissé.
    • À crédit : laissez le montant à 0. La vente sera enregistrée comme dette.
  4. Validez — cliquez sur « Valider la vente ». Le reçu s'affiche et le stock est mis à jour automatiquement.
